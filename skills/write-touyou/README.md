# write-touyou

touyou (藤井) 名義で、日本語の文章を**新しく書く**（生成・執筆・下書き）。本人の口語的なリズム・ゆらぎ・留保で書き、AI 臭 (講義モード・念押し・空虚な決め台詞) を避ける。

校正スキル [`proofread-touyou`](../proofread-touyou/) を**書く側に反転**させた姉妹スキル。校正で「触ってはいけない」とされる表現を、生成では積極的に使う。

## いつ発動するか

```
touyou 名義でこのブログの下書き書いて
このメモから esa 記事にして
アウトラインから本文を起こして
LT の原稿のドラフト作って
```

## 方針

整えすぎず、本人の肉声で書く。素材にない事実は創作しない。書き方の基準は SKILL.md にある。

## 個人辞書は proofread-touyou と共有

よく使う表現・嫌いな AI 寄り表現の辞書は [`proofread-touyou/SKILL.md`](../proofread-touyou/SKILL.md) 末尾の「touyouさんの個人辞書」にある。両スキルがそこを参照する。
