# touyou さんの語彙と個人辞書（校正と執筆の共有）

proofread-touyou と write-touyou の両方がここを読む。校正では**書き換えない・削らない**語彙、執筆では**内容と場面が合うところで使う**語彙。
語を足すとき・本人から指摘を受けたときは、SKILL.md ではなくここに書く。

## 目次

- 肉声の語彙＝保護リスト（一人称 / 文末 / 副詞 / 指示語 / 動詞 / カッコ書き / 接続詞）

## 肉声の語彙（校正での「保護リスト」）

| 種類 | touyou さんの言い方 | 寄せない先 |
|---|---|---|
| 一人称 | 「自分は」「自分が」「自分の」「自分も」 | 「私は」「筆者は」「僕は」。主語の省略（明らかな冗長以外） |
| 文末 | 「〜と思います」「〜と思いました」「〜と思っています」「〜してもらえればと思います」「〜してみてください」「〜なのではないでしょうか」「〜じゃないかなと思います」 | 「〜です」「〜でしょう」「〜と考えられます」「〜と言えるでしょう」への硬化。留保を残す |
| 口語的副詞・砕けた表現 | 「本当に」「ちょっと」「結構」「めっちゃ」「わりと」「けっこう」「ぶっちゃけ」「ようするに」「ちょっとばかし」「そもそも」 | 削除、「実に」「相当」「概ね」などの硬い漢語 |
| 柔らかい指示語 | 「ところ」「やつ」「もの」「こと」「あたり」「感じ」 | 「領域」「対象」「事項」「観点」 |
| 動詞 | 「考える」「使う」「やる」「作る」「書く」「触る」「見る」 | 「検討」「活用」「実施」「制作」「執筆」「使用」「確認」への漢語化 |
| カッコ書き | カッコで補足説明を入れる（「（HCI）」「（Chief Design Officer）」など）。親切心からの補足 | 削る、整理し直す |
| 接続詞 | 「ただ」「ですが」「では」「というわけで」「そこで」「もちろん」 | 「したがって」「ゆえに」「そのため」「結果として」 |

文頭の「ただ」「そこで」「ですが」「実際」や短い主題（「〜は」）の直後には、読点を置かないことが多い（一拍止まりすぎる、と本人が外している。個人辞書の具体例）。
執筆では置かずに書き、校正では直さずに提案として出す。

「〜と思います」「〜かな」「〜じゃないかな」は空疎な緩和ではなく肉声。避けるのは、AI が後付けする「〜と言えるだろう」「〜と考えられます」のような肉声のない緩和だけ。

## 個人辞書

ここはtouyouさん本人が書き足す欄。自分がよく使うけど他の人があまり使わない言い回し、絶対に校正で消されたくない口癖、好きな接続詞などを書き足してください。

### 自分がよく使う表現（保護したい）
本人から追加指定があった際に記録する。
- 「メイン／サブ」（「主な操作／副次的な操作」より。2026-10 Duo 対応記事）
- 「自作の〜」（「自前の〜」より。同記事）

### 自分が嫌いな（普段使わない）AI寄り表現
- 「先に書いておくと」（2026-10、Duo 対応記事。前置きなら「実のことを言うと」のように自分の言葉で入る。proofread-touyou の SKILL.md の操作1 にルール化済み）
- 「この記事に書く判断のほとんどが決まりました」のような、体験を「判断」「決定」に抽象化した言い方（同記事。本人は「この記事にまとめているポイントのほとんどに気づくことができました」）
- 「この穴は埋まりません」「〜も付いてきました」「先に送ります」のような比喩・ぼかした動詞（同記事。ai-slop-patterns.md A2 にルール化済み）
- 「ここまで作ってみて、気づいたことがあります。変わったのは〜だということです。」のような「ためて明かす」型（2026-07、他者の note 記事 https://note.com/toitoi1618/n/ndf35dbd2585b でこの型を見つけて「AIっぽい」と感じた実例。proofread-touyou の SKILL.md の操作1・指摘8 にルール化済み）
- 「セレモニー」（手続きや段数の多さを指す英語圏の開発用語。2026-10、Zenn の IntentTodo シリーズ 1/N に生成で入った「1 アクション追加のセレモニー (Repository → Service → Intent → AppShortcut) の段数が多い」を本人が「少しAI的かも」と指摘。「足すたびに触る場所が多い」のように、何が多いのかをそのまま書く）

- 「正直に言うと」型の前置き（2026-11、社内向けの App Intents 中心設計の記事。生成で見出し「正直に言うと、税もある」に入ったのを本人が「AIっぽい」と指摘。打ち明け話の体裁で一拍ためる前置きなので、見出しなら「大変なところもある」のように中身をそのまま書く）。ただし「正直なところ」「正直に」は本人も文脈次第で使うので、語があるだけで機械的に外さない。指摘するのは、見出しや段落の頭で一拍ためる前置き、打ち明けるほどでもない内容に付いている、同じ記事で繰り返している、のように AI っぽく読めるときだけ。迷ったら直さずに提案として残す。AI 以前の本人の使い方は [voice-baseline.md](voice-baseline.md) 2 章
- 「税」（コスト・手間を指す比喩。同記事の「払っている税もあります」「税もある」を本人が「AIっぽい」と指摘。英語圏の *tax* の直訳寄りの比喩なので、「実装する側で大変になるところ」「手間」のように何が大変なのかをそのまま書く。「セレモニー」と同じ型）

### 校正で「あれっ」と感じた具体例（蓄積用）
本人から具体例が提供された場合に記録し、一件の例から文体全体の禁止ルールに広げない。
- 2026-10 Duo 対応記事: 「そのぶん、ツールバーは」→「その分ツールバーは」（ひらがなに開きすぎたうえに読点が入り、リズムが崩れる）。「つまり閉じた画面では、**縦が足りず、横も右の列に取られる**。」→「つまり閉じた画面では縦も横も通常より短い領域になるわけです。」（「つまり」自体は本人も使う。崩れていたのは句点で切った言い切りのほう）
- 2026-10 同記事（最終レビュー続き）: 文頭の「ただ、」「そこで、」「ですが、」「実際、」や「〜は、」の直後の読点を本人が外した（例: 「ただ、Apple が開催した」→「ただ Apple が開催した」）。本人の感覚では一拍止まりすぎる、とのこと
- 2026-11 社内向けの貢献まとめ記事（生成→本人が直して公開）: 「たぶん誰にも気づかれていないと思います（笑）。」→「たぶんほぼわからないと思います笑」。「笑」はカッコで囲まず文末にそのまま付ける（AI 以前の「です！笑」と同じ）。「誰にも気づかれていない」ほど大げさな自虐にもしなかった
- 同記事: 「〇〇さんの Notion」→「〇〇の Notion」。自分も関わっている会社なので「さん」を外した。お客さんの会社には「〇〇さん」と付けるので、会社名から一律に外さない
