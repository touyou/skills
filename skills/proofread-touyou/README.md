# proofread-touyou

touyou (藤井) が書いた日本語の文章を、**AI 臭を残さずに**校正する。誤字脱字や事実誤認は指摘するが、文体・リズム・ゆらぎは積極的に保護する。

## いつ発動するか

```
このesa記事の校正お願い
ブログ下書きをレビューして
読んでチェックして
```

touyou 本人の口語的なリズム (一人称「自分は」、文末「〜と思います」、口語的副詞の混在など) で書かれた文章が対象。「いきおい」で書いた文章に AI が「読みやすさ」のために講義モードを混入させて本人の肉声を消すのを防ぐ。

touyou 名義で新しい文章を**書く**（生成・執筆・下書き）依頼は、姉妹スキル [`write-touyou`](../write-touyou/) が担当する。このスキルは既に書かれた文章の校正・推敲に専念する。

## 鉄則

- **迷ったら触らない** ── 「気になるけど直すほどでもない」は保留に倒す
- 誤字脱字 / 事実誤認 / 用語ミスは指摘する
- 文体・リズム・ゆらぎ・留保 (「〜かな」「〜気がする」「〜と思います」) は保護対象
- 機械的にスムーズにする変更 (「ですが」→「が」等) を勝手にしない
